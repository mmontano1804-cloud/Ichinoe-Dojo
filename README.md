# Ichinoe Dojo

## Add photos or videos
1. Open the `gallery` folder on GitHub.
2. Click **Add file → Upload files**.
3. Upload your new photo/video.
4. Click **Commit changes**.
5. Wait about 30–60 seconds for the **Update gallery list** Action to finish.

That's it. Do not edit `index.html` or `gallery-files.json`.

### Ordering
Files display alphabetically. Use names like:
- `13-new-photo.jpg`
- `14-training.mp4`
- `15-team.jpg`

The GitHub Action automatically updates `gallery-files.json` whenever the `gallery` folder changes.
