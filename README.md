# Ichinoe Dojo

## Updating the gallery

Just upload new `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`, `.avif`, `.mp4`, `.webm`, or `.ogg` files into the `gallery` folder and commit the change.

The website reads the folder automatically. You do **not** need to edit `index.html` or any JSON file.

### Order
Files appear alphabetically. If you want a specific order, start the filenames with numbers:

- `01-photo.jpg`
- `02-photo.jpg`
- `03-video.mp4`

That's it.
